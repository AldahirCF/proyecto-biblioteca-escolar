# Objetivo:

 Elegir entre arreglo escalonado y List<T> para representar títulos con distinta cantidad de ejemplares; implementar el ordenamiento por inserción para preservar el orden alfabético entre títulos con igual número de préstamos; aplicar búsqueda binaria sobre una copia ordenada por ISBN.
